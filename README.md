# 🧠 CNN Neural Networks — Deep Learning Portfolio

A comprehensive collection of deep learning projects using **CNNs**, **Transfer Learning**, and **Object Detection** across medical imaging and agricultural AI.

## 📂 Notebooks

| Notebook | Domain | Description |
|---|---|---|
| `Brain_tumour.ipynb` | Medical | Brain tumour classification from MRI scans |
| `Brain_tumor_complex.ipynb` | Medical | Advanced brain tumour detection |
| `Brain_tumour_csv.ipynb` | Medical | Brain tumour analysis with tabular data |
| `Radiologist.ipynb` | Medical | AI-assisted radiology support |
| `HeartFailure.ipynb` | Medical | Heart failure prediction |
| `Agricultural Kaggle.ipynb` | AgriTech | Crop classification from Kaggle dataset |
| `plant.ipynb` | AgriTech | Plant species classification |
| `Leaf Anomally_with_resnet.ipynb` | AgriTech | Leaf anomaly detection with ResNet |
| `Pytorch for leaf anomally.ipynb` | AgriTech | PyTorch leaf anomaly detection |
| `weeddetection.ipynb` | AgriTech | Weed detection in agricultural fields |
| `yolov8.ipynb` | Vision | Object detection with YOLOv8 |
| `yolov9.ipynb` | Vision | Object detection with YOLOv9 |
| `objdetection.ipynb` | Vision | General object detection |
| `ImageClassificationApex.ipynb` | Vision | Optimised image classification |
| `Computer vision.ipynb` | Vision | General computer vision experiments |
| `Data science.ipynb` | General | Data science and EDA fundamentals |
